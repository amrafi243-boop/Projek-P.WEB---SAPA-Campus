## Fungsi Folder dan File di Projek SAPA Campus

1. .vscode/
Menyimpan pengaturan Visual Studio Code agar penulisan kode lebih rapi dan konsisten.
    - settings.json: Mengatur format, indentasi, dan tampilan kode di VS Code.

2. assets/
Menyimpan file pendukung tampilan website.
    - css/: Menyimpan file CSS.
    - style.css: Mengatur warna, ukuran, tata letak, dan desain website.

3. includes/
Menyimpan komponen PHP yang digunakan bersama oleh beberapa halaman.
    - header.php: Mengatur bagian atas website, seperti logo dan navigasi.
    - footer.php: Mengatur bagian bawah website, seperti informasi dan hak cipta.

4. pages/
Menyimpan file PHP untuk setiap halaman publik.
    - alur.php: Halaman Alur Pengaduan.
    - faq.php: Halaman Pertanyaan Umum.
    - kategori.php: Halaman Kategori Laporan.
    - kontak.php: Halaman Informasi dan Kontak.
    - tentang.php: Halaman Tentang Kami.

5. index.php
Merupakan halaman utama (Beranda) sekaligus titik masuk utama website.

6. README.txt
Berisi dokumentasi, informasi, dan panduan penggunaan serta pengembangan proyek SAPA Campus.
